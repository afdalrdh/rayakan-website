## ✨ Fitur & Keunggulan

- **Desain Ultra-Luxury & Sinematik**: Terinspirasi dari estetika berkelas dunia [Cordially.io](https://www.cordially.io/) dengan tipografi *Instrument Serif* dan *Plus Jakarta Sans*.
- **Fullpage Hero Banner (No-Scroll)**: Tampilan satu halaman penuh yang imersif dan fit 100% viewport (`100dvh`), terkunci rapi tanpa scroll bar yang mengganggu.
- **3D Interactive Device Showcase**:
  - Mockup browser desktop dengan animasi amplop bertekstur dan *3D gold wax seal stamp*.
  - Mockup smartphone presisi dengan foto sinematik, monogram pasangan, dan tombol RSVP.
  - Tombol pertukaran perspektif 3D (**⇆**) yang memutar fokus perangkat secara mulus.
  - Efek parallax 3D interaktif mengikuti gerakan kursor mouse.
- **Bahasa Indonesia Penuh**: Seluruh teks, copywriting, dan alur komunikasi disesuaikan dengan bahasa Indonesia formal dan berkelas.
- **CTA Terintegrasi**:
  - Tombol **Pesan Sekarang** langsung terhubung ke Instagram resmi: [`instagram.com/rayakan.my.id`](https://instagram.com/rayakan.my.id).
  - Tombol **Lihat Template** terhubung ke katalog template undangan: [`wedding.afdalrdh.com`](https://wedding.afdalrdh.com).
- **Audio Ambience Berkelas**: Fitur musik latar lembut berbasis Web Audio API (harmoni harpa/piano akustik) tanpa dependensi file eksternal yang berat.
- **Responsif di Semua Perangkat**: Tampilan otomatis menyesuaikan secara sempurna di smartphone (iPhone/Android), tablet, maupun desktop monitor 4K.

## 🚀 Cara Menjalankan

Website ini dibangun murni menggunakan HTML5, CSS3 modern, dan Vanilla JavaScript tanpa dependensi eksternal yang rumit, sehingga dapat dibuka langsung:

1. **Buka Langsung di Browser**:
   Cukup klik dua kali berkas `index.html` pada komputer Anda.

2. **Atau Menggunakan Local Server (VS Code Live Server / Python)**:
   ```bash
   python3 -m http.server 3000
   ```
   Buka `http://localhost:3000` pada peramban Anda.
